# 中文詞語補全

狀態：第一版試作

日期：2026-10-05

智慧注音組字區中的「人工」完成讀音後，游標在末尾時，橫向候選窗最多顯示三個詞尾（例如「智慧」「呼吸」「流產」），預設標亮第一項。按 Tab 把選中詞尾補進組字區，單按 Tab 補入時仍由 Enter 送出；按住 Shift 並以 Tab 切換後，放開 Shift 會接受選中項目並直接送出整段組字。補入組字區的字保留讀音，仍可選字、移動游標及刪除。

## 開關

好打注音沿用「聯想詞提示」開關：開啟時提供組字中的中文詞語補全，不再同時啟用送出單字後的舊聯想詞。關閉時不顯示補全；其他輸入法仍使用原本的聯想詞功能。

## 按鍵與提示

- 在已有中文字、沒有標記選取、游標在組字末尾時顯示。若還有待完成注音，依其前綴篩選下一字讀音，例如「演ㄙ」提示「演算法」；此時候選顯示完整詞語。
- 使用既有橫向候選窗，一頁最多三個不重複詞尾，不顯示數字快捷鍵；上方以小字顯示「TAB選取，shift+TAB切換」。
- 提示存在時，Tab 接受選中建議，按住 Shift，每按一次 Tab 向下一項循環切換，放開 Shift 時接受選中項目並送出整段組字；也可點選詞尾。
- 只有至少按過一次 Shift＋Tab 才觸發放開送出；Esc、繼續輸入、切換選字窗或重設組字會取消此動作。單按 Shift 保留原本的中英切換行為。
- 右方向鍵關閉提示並保留原有游標操作，不接受補全。
- Esc 關閉提示並保留組字；組字文字未變時不再顯示同一提示。
- 繼續打注音會依下一字的注音前綴重新篩選提示；移入句中、開啟一般候選窗會收起提示。切換選字窗方向時，IMK host 明確隱藏上一個視窗，避免水平補全窗與垂直選字窗同時留在畫面。
- 沒有提示時，Tab 保留原本切換斷詞的行為，右方向鍵保留移動游標的行為。
- 補全後刪除最後一字，既有語言模型會重新選擇剩餘讀音的同音字，與一般組字編輯一致。

## 查詢與插入

從組字末尾取 1–7 個中文字作為前綴，優先嘗試最長前綴。沒有待完成注音時，依文字及已輸入讀音同時比對 release lexicon 與使用者詞庫；有待完成注音時，未鎖定的自動組字前綴允許同音字候選，以已輸入讀音加上下一字注音前綴比對，取完整詞長不超過 8 字的候選，以詞頻排序，沒有待完成注音時去除重複詞尾，有待完成注音時去除重複完整詞語，最多取三個建議。候選長度符合現有 graph 的詞長上限。

查詢使用既有 qstring 索引的範圍查詢，不要求 current 索引、不修改 release DB schema。接受時先在 graph 副本加入詞尾讀音，確認完整詞候選存在，再替換原 graph；缺少單字讀音或斷詞阻擋時不會留下半段補全。

尚未完成的下一字注音及輸出編碼篩選在 SQL 的 WHERE 中完成，再排序與限筆數；不先截取原排名，避免相關詞被不符讀音的高分詞擠掉。接受成功後才清空待完成注音，失敗或取消時保留原輸入。

此版尚未加入補全偏好學習或送出後續寫。顯示及接受補全不寫入新的學習紀錄；一般手動選字仍走原本的學習流程。

- `Scripts/test-learning-store.sh` 包含獨立詞庫 fixture 的 `TestPhraseCompletion`：單字前綴與多字詞尾、排名、同音詞、編碼篩選、user overlay、斷詞與失敗時原子性。
- `Scripts/test-core-smoke.sh` 包含真實詞庫的「人工 → 人工智慧」按鍵測試：Tab、Shift＋Tab 循環與放開 Shift 送出、取消與重複放開、絕對索引選取、右方向鍵不補全、Esc、Backspace、Enter、句中 Tab、注音聲調與一般選字窗。
- macOS 實際浮動窗的位置及手感需在 Dev 輸入法中試用。

## 排序限制

目前沿用詞庫組字分數，並非依補全使用情境排序。支援一字前綴不代表所有常見詞都會進入前三項：目前實際詞庫中「演算法」在「演」前綴排名第 16，「捷運站」則排在「捷運系統」「捷運局」之後。改善這些例子需要補全專用的搭配排名、上下文或個人選取紀錄，不能只靠縮短前綴或優先短詞。

「演ㄙ」則會排除「演講／演出／演員」等不符下一字讀音的詞，實際詞庫的前三項為「演說／演算法／演算」。這是讀音篩選，不代表已加入情境或個人化排名。

## 同音字重新判斷

「工ㄋ」可提示「功能」及「工農」，不把自動選出的「工」當作已確認文字。查詢本身不改組字；接受「功能」時，才把「工」換成「功」、補入「能」的完整讀音並清空「ㄋ」。沒有待完成注音時仍沿用文字前綴比對。若前綴和 graph 中既有選字 override 重疊，保留原字、不跨同音字補全；手動選定「工」後仍只提示以「工」開頭的詞。

## 候選窗位置

macOS 與 Windows 的橫向補全窗優先置於目前文字行上方，保留少量間距；上方空間不足時改放下方，並限制於目前螢幕的可用範圍。一般直向選字窗保留原位置。
