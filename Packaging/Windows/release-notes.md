千秋輸入法的 Windows 預覽版。下載 `ChiaKey-Windows-@VERSION@-Setup.exe` 執行即可安裝。

- 支援 Windows 10 / 11 的 x64 版，64 位元與 32 位元程式都能打字；ARM64 版尚未支援。
- 包含好打注音、傳統注音、倉頡、簡易與自訂 .cin 字表，以及符號表（Ctrl+Alt+.）、聯想詞與詞彙編輯器。
- 安裝後，已經開著的程式要重新開啟才會載入輸入法。若輸入法清單裡沒有千秋輸入法，請到「設定 > 時間與語言 > 語言與地區」加入「中文 (繁體，台灣)」。
- 自訂詞、學習記錄與設定存在 `%APPDATA%\ChiaKey`，升級與解除安裝都會保留。
- 「偏好設定 > 更新」參照 Mac 版排版，開啟頁面即檢查本體與詞庫；兩者各有獨立的檢查、安裝與自動更新選項（預設皆開啟）。「接受 Beta 版」獨立勾選且預設關閉。背景每天檢查一次，發布滿三天才更新；本體安裝時需要 Windows 權限確認。詞庫校驗與引擎載入通過後才切換，失敗保留原詞庫。
- 修正更新頁在縮放時的文字裁切。偏好設定使用 Mac 的橘色角色圖示，詞彙編輯器使用紫色角色圖示；輸入法識別圖示保留透明背景的「千」字，中英指示器依輸入法顯示「注／倉／簡」。

### 尚未簽章

這個版本的檔案**尚未簽章**。執行安裝檔時 SmartScreen 會出現「Windows 已保護您的電腦」，請按「其他資訊 > 仍要執行」。開啟了「智慧型應用程式控制」（Smart App Control）的電腦會直接擋下，暫時無法使用。
