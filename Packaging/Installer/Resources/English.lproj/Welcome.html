Welcome to ChiaKey.

ChiaKey is a Yahoo! Kimo Input Method revival project created by Chiaki, released as a completely free and open-source input method.

This package installs the input method and includes the self-made ChiaKey comprehensive lexicon.

macOS may ask you to allow a new input source during the install. Click "Allow" when it does. The installer waits up to half a minute for your answer, so it is normal for it to pause on "Running package scripts..." while that prompt is open.

The goal of this input method is to preserve Yahoo! Kimo Input Method's feel for Traditional Chinese bopomofo input while making the project buildable, testable, maintainable, and releasable on modern Apple Silicon Macs.
